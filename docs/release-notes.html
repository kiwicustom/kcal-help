Release Notes

kCal Buddy by version line — the main idea of each era.

v0.8.xCurrent
Together

How do we improve together?

  • Spaces and shared challenges
  • iPhone + Android apps
  • Buddy Home coach loop for real daily use
  • Help Platform + Buddy Academy
v0.7.x
Personal

How do I improve myself?

  • Buddy Home: log → Foodiary → Progress
  • Voice + text logging that sticks
  • Targets, fuel, and habit coaching
v0.6.x
Stability

Make the daily loop trustworthy.

  • Diary accuracy and day handling
  • Mobile layout hardening
  • Invitation-only beta ops
v0.5.x
Body data

Food, drink, and wearables connect.

  • Liquids as first-class (water, coffee, volume)
  • Quick food in Foodiary
  • Oura and health integrations
v0.4.x
Buddy voice

Talk to Buddy instead of fighting forms.

  • Voice as a primary log door
  • Preview → confirm before save
  • Usable mic in real rooms
v0.3.x
Progress

See whether the day is working.

  • Calorie and macro targets
  • Today’s progress after logging
  • Early coaching from what you ate
v0.2.x
Foodiary

A diary you can correct.

  • Foodiary to review and fix meals
  • Portions, edits, day browsing
  • Home captures; Foodiary proofreads
v0.1.x
Spark

First working Buddy — log something, see something.

  • Core food logging
  • Buddy as the intelligent helper
  • Invitation-only beta begins

Patch-level engineering detail lives in the monorepo CHANGELOG.md.
